# 🛡️ SecureTrace: Advanced Anti-Theft Tracking System

SecureTrace is a professional, full-stack location tracking web application designed to locate lost or stolen devices. It utilizes GPS data to securely track devices in real-time.

##  Features
- **Multi-User Authentication:** Secure user registration and login system.
- **Unique Tracking Key:** Each user is assigned a unique, secret `TRK-XXXXXX` key to bind their devices.
- **Real-Time Tracking:** Live location updates pushed directly to the Command Center dashboard.
- **Secure Database Storage:** Location data and user credentials are encrypted and stored in MongoDB.
- **Cyberpunk UI / HUD:** Custom-built dark theme interface with matrix rain canvas and radar animations.

##  Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Leaflet.js (Maps API)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose ODM)
